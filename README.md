# imdUSD: "Nobody Works Here"

Production material for a 2-minute, music-and-sound-only film about imdUSD and the IdentityMD agent
swarm. The swarm paints the background plates. The animation, lettering, sound and edit are done
separately.

- `BRIEF.md`: the style-frames brief (story, two visual styles, palettes, every frame).
- `refs/engraved/`: the engraved register (frames from our previous film, and the banknote).
- `refs/pixel/`: the pixel register (our own pixel Pepe and the consensus grid).

The character Pepe the Frog was created by Matt Furie. The pixel and engraved renderings here are our
own drawings, used non-commercially.
